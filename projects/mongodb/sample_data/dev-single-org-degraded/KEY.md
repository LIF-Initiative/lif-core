# Synthetic learners: key

Generated by `python3 -m lifsynth --seed 2026 --seed-key dev-single-org`. Cases follow the LIF Synthetic Data Test-Case Matrix (2026-11-18), which is kept outside this repository. Records describe each learner as of 2026-10-01; all attend State University.

## Folders

- `dev-single-org/`: V01-V24, the valid group for the default demo seed. The files sit beside the six original records in `projects/mongodb/sample_data/dev-single-org/`.
- `dev-single-org-degraded/`: D01-D11B, for a separate validation or demonstration seed. No script loads it; `README.md` describes each record and how to load the folder on its own. Each record except D11B keeps its control's student number, so never load both folders into one database. For a mixed demo, load V12-V24 with this folder: none of them is a control.
- `demo_personas-degraded.py.txt`: lines for `components/lif/demo_personas/core.py`. The Advisor login and the Learner Data Export picker list only learners in that file, which already holds the 24 valid learners. Use the valid lines or the degraded lines, not both: the degraded lines reuse the valid learners' emails. D11A and D11B share one email, so the Advisor login can't tell them apart.
