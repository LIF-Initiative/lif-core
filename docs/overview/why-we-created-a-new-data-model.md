# Why We Created a New Data Model

The rationale for the LIF data model: bringing existing learner data standards together into one comprehensive, flexible, interoperable model.

The Learner Information Framework (LIF) data model was created to support a more complete, connected, and flexible understanding of learner data.

Many learner data standards already exist, and each contributes important value. Some are focused on K-12 education, some on postsecondary education, some on workforce readiness, credentials, employment, competencies, or learning and employment records. However, most were designed to solve a specific problem within a specific context. As a result, each standard tends to describe only part of a learner's journey.

LIF was created because no single existing model fully represented the broader picture we needed: a comprehensive record of data associated with a learner across education, training, credentials, skills, employment, and future opportunities.

## Our Data Model Philosophy

The LIF data model is not intended to replace existing standards. Instead, it is designed to bring them together.

Our approach begins with the recognition that valuable learner data already exists across many systems and standards. Rather than starting from scratch, LIF uses crosswalk analysis to compare existing education and workforce data models, identify overlap, understand gaps, and select common, meaningful elements that can serve as part of a shared normative model.

This gives LIF a consistent structure for representing learner information while still allowing data to come from many different sources.

## Why a Normative Model Matters

A normative model gives systems a shared target structure. It defines how learner information should be represented when data is exchanged, translated, or made available through LIF-aligned tools and APIs.

This matters because different systems may describe similar concepts in different ways. For example, one system may store assessment results, another may store credentials, and another may store skills or employment information. Without a shared structure, these pieces of information remain fragmented.

The LIF data model provides a way to align those pieces so they can be understood together as part of a broader learner record.

## Built to Be Comprehensive, But Also Flexible

The goal of LIF is to support a longitudinal, multi-context view of the learner. That means the model must be broad enough to include information from many stages of a learner's academic and professional journey, including identity, academic history, assessment history, credentials, course completion, skills, employment, and related learner experiences.

At the same time, the model must remain flexible. Not every use case requires every data element. Not every institution, vendor, or organization will have the same data. LIF is designed to support a core structure that can expand over time as new use cases, standards, and data needs emerge.

This flexibility is central to the model's philosophy. LIF does not assume that the data model is finished or fixed. It is intended to evolve.

## Designed for Translation and Interoperability

A major reason for creating the LIF data model is to make learner data easier to translate between systems. The model is paired with mapping and transformation tools so that data from one standard or system can be converted into the LIF structure, and potentially from the LIF structure into another model.

This makes LIF more than a list of data elements. It is a framework for understanding how learner data relates across standards, how equivalent or similar concepts align, and how information can move consistently between systems.

## The Bigger Purpose

LIF was created to help the education and workforce ecosystem move toward a more connected view of the learner.

Instead of treating learner data as a set of disconnected records spread across institutions, systems, and standards, LIF provides a way to bring those records into a shared model that is comprehensive, flexible, and interoperable.

We created the LIF data model because learners are more than the data captured by any one system. Their records should reflect the full range of their academic, professional, and lifelong learning journey.
