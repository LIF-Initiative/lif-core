# Use Case Examples

Short descriptions of three ways LIF is used: learner wallets, dual enrollment, and contextual data for AI tools.

## Learner Wallet

LIF makes learner wallets more powerful by providing a clean, consistent way to pull together data from many different systems—such as SIS, LMS, credential platforms, or skills records—and present it in one place. Instead of organizations manually gathering and formatting information, LIF handles the local aggregation, transformation, and delivery of data through a structured model. This allows learner wallets to give individuals a complete, accurate view of their achievements and lets learners control how their information is shared.

## Dual Enrollment

For dual enrollment programs, LIF helps schools and colleges seamlessly exchange records that are typically stored in different formats and systems. Using a standardized data model and translation tools, LIF converts each institution's information into a single, consistent structure. This enables automatic assembly of combined records—such as unified transcripts—so learners, counselors, and institutions have accurate, aligned information without the manual reconciliation that typically slows the process.

## Contextual Usage for AI

LIF provides the structured data layer needed for AI systems to deliver personalized, context-rich guidance to learners. By offering a standardized interface for AI tools and organizing the data that those tools can access, LIF ensures that AI agents have the context they need from the start instead of relying on fragmented memory or repeated questions. It also supports writing new information back into the system so AI interactions can evolve with the learner's goals, all while respecting consent, governance, and data-sharing rules.
